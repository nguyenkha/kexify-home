Pertanyaan yang Sering Diajukan

Umum

Apa arti "kexify"?

Keys simplified. Itu saja.

Apa itu kexify?

Dompet MPC berkustodi mandiri tempat dua bagian kunci independen dibuat bersamaan — satu di browser Anda, satu di server. Tidak pernah ada satu private key utuh. Tidak ada pihak yang memegang kunci utuh.

Apa itu MPC?

Multi-Party Computation — teknik kriptografi saat beberapa pihak menghitung sebuah fungsi bersama tanpa membuka masukan masing-masing. Di kexify, dua bagian kunci menandatangani transaksi tanpa pernah digabung menjadi private key utuh.

Apakah kexify open source?

Ya. Dibangun di atas pustaka cb-mpc milik Coinbase (fork kami). Aplikasi web-nya open source dengan lisensi MIT: kexify-web. Server dan aplikasi iPhone belum open source.

Apakah kexify benar-benar gratis?

Paket gratis tetap gratis selamanya, tanpa iklan, dan sudah termasuk semua keamanan dasar: batas harian, alamat tepercaya, blokir persetujuan tak terbatas, pemeriksaan alamat berisiko, pembekuan, cadangan, dan mode pemulihan. Paket Premium direncanakan untuk fitur yang butuh biaya untuk dijalankan, seperti iPhone sebagai perangkat persetujuan, penandatanganan QR offline, dan peringatan instan. Premium segera hadir dan harganya belum ditetapkan. Keamanan dasar tidak akan pernah dipindah ke balik paywall.

Kenapa kexify tidak punya fitur swap, staking, atau DeFi?

Memang disengaja. Dompet sebaiknya mengerjakan satu hal dengan baik — menyimpan dan menandatangani. Swap, pinjaman, dan bridge sudah ditangani dApp seperti 1inch, Aave, dan MyEtherWallet. Sambungkan ke salah satunya lewat WalletConnect. Fitur lebih sedikit berarti bug lebih sedikit dan permukaan serangan lebih kecil.

Apa filosofi desainnya?

Tiga prinsip: tetap sederhana, fokus sebagai dompet, dan hanya mengoptimalkan UX dan keamanan. Setiap keputusan fitur disaring lewat ketiganya. Kalau tidak membuat dompet lebih mudah dipakai atau lebih aman, fitur itu tidak dirilis.

Apakah ada garansi?

Tidak. kexify adalah proyek pribadi yang disediakan apa adanya, tanpa garansi. Anda bertanggung jawab atas kunci dan dana Anda sendiri. Meski begitu, kode aplikasi web-nya open source, jadi Anda bisa memeriksa cara kerjanya.

Untuk siapa kexify?

Dua kelompok. Orang yang baru mengenal kripto dan ingin dompet yang mencegah kesalahan umum: tanpa frasa seed, dengan batas harian, dan server yang menolak tanda tangan berisiko. Serta developer yang ingin WalletConnect, testnet, RPC sendiri, dan jalan keluar yang tidak bergantung pada server kami.

Apakah ada aplikasi iPhone?

Masih dalam pengujian dan belum ada di App Store. Aplikasi web di my.kexify.app sudah berfungsi sekarang di browser modern mana pun, termasuk Safari di iPhone.

Keamanan

Siapa yang memegang kunci saya?

Tidak ada yang memegang kunci utuh. Satu bagian ada di browser Anda (dienkripsi dengan passkey atau frasa sandi), bagian lainnya di server (dienkripsi dengan AES-256-GCM). Keduanya harus bekerja sama untuk menandatangani.

Bagaimana kalau server mati?

Pakai Mode Pemulihan. Ekspor bagian kunci server Anda lebih dulu (di Mode Ahli), lalu tandatangani secara lokal di browser dengan kedua bagian kunci. Frontend-nya open source, dan ada juga alat CLI untuk menggabungkan kedua bagian menjadi kunci utuh. Tidak perlu server.

Bisakah server mencuri dana saya?

Tidak. Server hanya punya satu bagian — server tidak bisa menandatangani sendirian. Protokol MPC 2-of-2 mencegah penandatanganan sepihak secara desain. Frontend-nya open source — Anda bisa mengaudit kodenya bahkan menjalankannya sendiri.

Bagaimana bagian kunci disimpan?

Browser: dienkripsi AES-GCM dengan PRF passkey WebAuthn atau frasa sandi (PBKDF2). Server: AES-256-GCM dengan kunci turunan HKDF per pengguna. Semua dalam pengiriman: TLS 1.3.

Apa itu pemeriksaan penipuan GoPlus?

Sebelum ikut menandatangani, server memeriksa penerima (atau penerima izin pada persetujuan token) terhadap basis data GoPlus Security berisi alamat penipuan, phishing, dan alamat yang terkena sanksi. Jika alamat ditandai, server menolak menandatangani. Fitur ini aktif untuk setiap dompet tanpa pengaturan. Jika GoPlus tidak menjawab tepat waktu, pengiriman tidak diblokir, jadi anggap ini jaring pengaman tambahan, bukan jaminan.

Apa bedanya kexify dengan dompet MPC lain seperti ZenGo?

Keduanya memakai MPC. Dengan kexify, Anda bisa mengekspor kedua bagian kunci dan menandatangani tanpa server kami, penandatangan bersama menegakkan aturan yang Anda tetapkan sendiri (batas harian, alamat tepercaya, masa tunggu di atas batas), dan aplikasi web-nya open source.

Bagaimana MPC dan Mesin Kebijakan bekerja bersama?

Bayangkan brankas yang butuh dua kunci. Anda memegang satu kunci, server memegang yang lain. Tidak ada yang bisa membuka brankas sendirian. Tetapi server juga bertugas sebagai penjaga — sebelum memutar kuncinya, server memeriksa aturan Anda: Apakah jumlah ini masih dalam batas pembelanjaan? Apakah alamat ini ada di daftar yang disetujui? Apakah akun sedang dibekukan? Jika ada aturan yang dilanggar, server menolak ikut menandatangani dan transaksi itu tidak bisa terjadi.

Kalau server menegakkan aturan, apakah server juga bisa memblokir saya secara tidak adil?

Server hanya menegakkan aturan yang Anda atur sendiri. Dan jika Anda tidak setuju dengan server, ada jalan keluar: ekspor kedua bagian kunci dan tandatangani transaksi sepenuhnya sendiri di Mode Pemulihan. Server tidak akan pernah bisa menyandera dana Anda.

Penggunaan

Blockchain apa saja yang didukung?

Chain EVM (Ethereum, Base, Avalanche, Polygon, Arbitrum, BSC...), Bitcoin, Solana, XRP, TRON, TON, Algorand, Cardano, Stellar, Litecoin, Dogecoin, dan Bitcoin Cash — beserta testnet dan token-nya.

Bagaimana cara menandatangani transaksi?

Mulai dari aplikasi atau sambungkan lewat WalletConnect. Kedua bagian kunci ikut dalam beberapa putaran MPC, biasanya beberapa detik, untuk menghasilkan tanda tangan yang valid.

Apa itu Mesin Kebijakan?

Lapisan keamanan yang Anda atur sendiri, berisi aturan yang ditegakkan server sebelum ikut menandatangani. Bahkan jika seseorang mendapat akses ke browser Anda, kebijakan membatasi apa yang bisa mereka lakukan.

Jenis kebijakan apa yang bisa saya atur?

Batas harian: jumlah USD per 24 jam bergulir. Kirim ke: alamat mana saja, atau hanya alamat tepercaya. Di atas batas: blokir pengiriman, atau biarkan lewat setelah menunggu 1 atau 24 jam. Semuanya ditegakkan oleh server sebelum ikut menandatangani. Di luar aturan Anda, persetujuan token tak terbatas dan alamat yang ditandai selalu ditolak. Mode Ahli juga punya editor aturan kustom yang lengkap.

Kenapa ada masa tunggu 24 jam?

Untuk mencegah penyerang melonggarkan aturan Anda lalu langsung memanfaatkannya. Perubahan yang membuat aturan lebih longgar, misalnya batas yang lebih tinggi, menunggu 24 jam. Perubahan yang membuatnya lebih ketat berlaku seketika. Jika bukan Anda yang mengubahnya, Anda punya waktu untuk membekukan akun.

Bisakah saya membekukan akun?

Bisa, dengan satu klik pada tautan pembekuan di email keamanan kexify. Berlaku seketika dan memblokir semua penandatanganan. Untuk membuka pembekuan, perlu passkey Anda (atau bukti dari dompet Anda) lalu menunggu 24 jam, jadi orang yang mencuri login Anda tidak bisa membatalkannya dengan cepat.

Apa itu Mode Ahli?

Kumpulan kontrol lanjutan yang gratis: jaringan uji, pemilihan UTXO, percepatan Replace-By-Fee untuk Bitcoin dan Litecoin, nonce dan biaya kustom, mode hanya tandatangani dengan penyiaran terpisah, penandatanganan pesan mentah, RPC dan explorer kustom per chain, editor konfigurasi JSON, aturan kustom, dan pencadangan bagian kunci lengkap. Nonaktif secara default; aktifkan di Pengaturan. Dogecoin tidak punya RBF, jadi pengiriman DOGE tidak bisa dipercepat.

Bisakah saya memakai kexify tanpa memberikan email?

Bisa. Login anonim memungkinkan Anda membuat dompet tanpa email atau data pribadi apa pun. Bagian kunci Anda disimpan secara lokal di browser, diamankan dengan frasa sandi. Mode ini dirancang untuk pengguna teknis yang paham pengelolaan kunci blockchain — tidak ada pemulihan akun jika Anda kehilangan frasa sandi dan bagian kunci.

Batasan

Kenapa saya hanya bisa membuat satu dompet?

Setiap dompet menyimpan bagian kunci terenkripsi di server dan memakai waktu pemrosesan server untuk menandatangani, jadi paket gratis mendapat satu dompet per akun. Dompet yang dibuat sebelum batas ini tetap berfungsi. Sub-akun tambahan akan hadir bersama Premium.

Kenapa dibatasi 50 input per transaksi (UTXO)?

Setiap tanda tangan MPC butuh beberapa putaran komputasi antara browser Anda dan server. Di chain UTXO (Bitcoin, Litecoin, dll.), setiap input butuh tanda tangan terpisah. Batas 50 menjaga waktu penandatanganan tetap wajar dan melindungi server. Untuk kebanyakan transaksi, 50 input sudah lebih dari cukup.

Kenapa koneksi RPC kadang lambat atau tidak stabil?

kexify memakai endpoint RPC publik gratis secara default untuk sebagian besar chain. Endpoint ini bisa dibatasi lajunya, padat, atau sesekali mati. Untuk keandalan dan kecepatan lebih baik, aktifkan Mode Ahli, buka Pengaturan, dan ganti RPC default dengan endpoint milik Anda (dari Alchemy, Infura, QuickNode, dll.) — kebanyakan punya paket gratis yang cukup besar dengan API key.

Apakah ada batas untuk email dan permintaan penandatanganan?

Ya. Email magic link, permintaan API, dan operasi penandatanganan semuanya dibatasi lajunya untuk mencegah penyalahgunaan. Jika terkena batas, tunggu sebentar lalu coba lagi. Batas ini cukup longgar untuk pemakaian normal — hanya berlaku saat ada pola aktivitas yang tidak biasa.

Kenapa kexify memakai Cloudflare Turnstile?

Turnstile adalah alternatif CAPTCHA yang ramah privasi dan berjalan tak terlihat di latar belakang. Ia melindungi layanan dari bot dan penyalahgunaan otomatis — tanpa teka-teki yang mengganggu atau pelacakan. Anda jarang akan menyadarinya.

Developer

Bisakah saya memakai jaringan uji?

Ya. Aktifkan Mode Ahli, lalu aktifkan jaringan uji di Pengaturan. Tersedia: Ethereum Sepolia, Base Sepolia, Solana devnet dan testnet, TRON Nile dan Shasta, testnet Bitcoin dan Litecoin, testnet XRP, Stellar, TON dan Algorand, serta Cardano PreProd.

Metode WalletConnect apa yang didukung?

WalletConnect v2. EVM: eth_sendTransaction, personal_sign, eth_sign, eth_signTypedData_v4. Solana: solana_signTransaction, solana_signAndSendTransaction, solana_signMessage. TRON: tron_signTransaction, tron_signMessage. Setiap permintaan melewati peninjauan dan pemeriksaan server yang sama seperti pengiriman biasa.

Apakah ada alat baris perintah?

Ya, CLI Bun di repo kexify-web. Alat ini memakai kedua file kunci Anda dan tidak pernah memanggil server kexify. recover menampilkan alamat Anda di setiap chain dan mengekspor kunci Anda: hex, atau WIF untuk Bitcoin, Litecoin, dan Dogecoin. Ekspor Ed25519 (Solana, Stellar, TON, Algorand, Cardano) adalah kunci mentah, bukan seed, sehingga dompet lain menampilkan alamat yang berbeda: pindahkan dana itu dengan mode pemulihan di aplikasi web. connect menandatangani permintaan WalletConnect dari dApp EVM dan Solana secara lokal. CLI tidak bisa mengirim sendiri.

Apa yang dilihat server kexify?

Saldo dan riwayat dibaca dari jaringan publik terlebih dahulu, dari perangkat Anda. Hanya saat sumber publik gagal, aplikasi bertanya ke server kexify, yang hanya menjawab untuk alamat dompet Anda sendiri dan membacanya dari penyedianya, jadi penyedia itu melihat alamat tetapi tidak melihat perangkat Anda. Buku alamat Anda disinkronkan dengan enkripsi end-to-end memakai kunci yang berasal dari key share Anda sendiri: server hanya menyimpan ciphertext. Simulasi transaksi berjalan dari perangkat Anda ke node publik, di chain EVM dan Solana; ini hanya perkiraan dan tidak pernah memblokir pengiriman. Mode pemulihan tidak memakai satu pun dari ini dan tetap bekerja walau server sudah tiada.

Teknis

Kriptografi apa yang dipakai?

ECDSA (secp256k1) untuk chain EVM, Bitcoin, Litecoin, Bitcoin Cash, Dogecoin, XRP, dan TRON; EdDSA (Ed25519) untuk Solana, Stellar, TON, Algorand, dan Cardano. Ditenagai pustaka WASM cb-mpc milik Coinbase yang berjalan langsung di browser Anda.

Apa itu cb-mpc?

Pustaka kriptografi threshold milik Coinbase. Kami memakai fork yang dikompilasi ke WebAssembly agar berjalan di dalam browser.
